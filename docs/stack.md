# dwPortal 技术栈（已锁定）

> 状态：已锁定（2026-07-28）

---

## 1. 前端（app/web）

- **框架**：Vite + React + TypeScript
- **路由与状态**：按需使用，v0 保持简洁
- **样式**：暂不锁定，留给视觉阶段

---

## 2. 后端（app/api）

- **语言**：Go
- **职责**：读取 `config.yaml`，提供服务列表 API，实现来源判断跳转逻辑
- **热更新**：请求时检测文件状态；有效新配置原子替换内存快照，无效配置保留上一份
- **交付**：生产构建将 Vite 静态资源嵌入 Go 二进制，由同一进程提供页面与 API
- **配置读取策略**（路径优先级）：

  1. **第一优先级**：`DWPORTAL_CATALOG`（兼容旧名 `DWPORTAL_CONFIG`）
  2. **第二优先级**：与后端二进制文件相同目录
  3. **第三优先级**：开发环境与当前工作目录

---

## 3. 配置与脚本

- **目录契约**：配置包含 `schema_version`；生产通过 `DWPORTAL_CATALOG` 指向 `/var/lib/dwportal/catalog.yaml`
- **生成脚本**：使用 **Python** 编写（独立可执行）
  - 脚本只读解析指定的 Caddyfile，原子生成版本化服务目录
  - 脚本和门户都不写入或重载 Caddy 配置
  - 不承担运行时逻辑

---

## 4. 契约

- `shared/contract`：定义 `ServiceItem`（服务条目）类型
- 前后端及脚本共用此定义
